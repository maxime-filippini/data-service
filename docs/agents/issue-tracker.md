# Issue tracker

Publish specifications and track implementation work in GitHub Issues for
`maxime-filippini/data-service`. The maintainer confirmed this convention during
the workflow simplification specification.

Apply `ready-for-agent` to specifications published through to-spec after the
required test-seam review. This label does not authorize production deployment.
Keep the repository specification and published issue aligned when revising scope.

Use the root glossary and relevant ADRs for domain terminology and decisions.

The workflow simplification specification is published as
[issue #29](https://github.com/maxime-filippini/data-service/issues/29); its local
source is [the workflow service spec](../specs/workflow-service.md).
