A personal market-data and portfolio workflow service on Cloudflare Workers. It
stores whole **workflow definitions** as data, runs their ordered steps with
Effect inside **Cloudflare Workflows**, calls one **Python operation service**
for normalization and numerical work, and explicitly publishes Parquet datasets
to R2 by dataset name and subject.

Client apps read published datasets either through the authenticated API or
directly from R2 at stable keys:

```txt
processed-market-data/dataset=prices_eod/symbol=AAPL.US/data.parquet
processed-market-data/dataset=portfolio_volatility/portfolio=<portfolio-id>/data.parquet
```

## The big picture

```mermaid
flowchart LR
  subgraph Clients
    apps[Client apps]
    ops[Operator<br/>curl / scripts]
    browser[App user]
  end

  subgraph Worker["data-service Worker"]
    api[Management API /api<br/>Bearer token]
    dash[SvelteKit app + /app-api<br/>Cloudflare Access]
    cron[Hourly cron<br/>scheduledWorkflowTick]
  end

  wf[DefinitionRunWorkflow<br/>Cloudflare Workflows]
  eng[CalculationEngine<br/>Python container]

  provider[(EODHD API)]
  d1[(D1<br/>state & metadata)]
  raw[(R2 raw-market-data<br/>runs/ 30d expiry)]
  processed[(R2 processed-market-data<br/>published datasets)]

  ops --> api
  browser --> dash
  cron --> wf
  api --> wf
  dash --> wf
  wf --> provider
  wf --> raw
  wf -- POST /operations/:name --> eng
  eng --> raw
  eng -- read published prices --> processed
  wf -- publish dataset --> processed
  api & dash & cron & wf --- d1
  apps -- read Parquet --> processed
```

One execution model serves both subject scopes:

<CardGrid>
  <Card title="Asset workflows" icon="download">
    Each enabled asset assignment runs daily at its definition's UTC hour (or on
    demand): download provider JSON in Effect, normalize to Parquet in Python,
    and explicitly publish `prices_eod`.
  </Card>
  <Card title="Portfolio workflows" icon="puzzle">
    Each enabled portfolio assignment resolves its dated holdings snapshot,
    waits durably for matching upstream asset publications, runs Python ex-ante
    volatility, and publishes `portfolio_volatility`.
  </Card>
</CardGrid>
